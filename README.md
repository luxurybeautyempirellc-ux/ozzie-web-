# Ozzie Marketing — Website

Single-page marketing site for Ozzie Marketing (Houston, TX), built to match the
dark/purple agency design mockup. Everything lives in one file: **`index.html`**.

## How to upload / host it

Pick whichever is easiest for you:

- **Netlify / Vercel**: drag-and-drop the `index.html` file (or connect this repo) — live in under a minute, free tier available.
- **GitHub Pages**: Settings → Pages → deploy from this branch, root folder. Your site will be live at `https://<username>.github.io/ozzie-web-/`.
- **Any web host / GoDaddy / Bluehost**: upload `index.html` via their File Manager or FTP and rename it to `index.html` in your `public_html` (or equivalent) root folder.
- **Custom domain**: point `ozziemarketing.com` at whichever host you choose and it'll just work — no other files required.
